How it works

1
On page load, the app fetches data/store.json from your GitHub repo via the Contents API.
2
Every time you add, edit, or delete — the change is committed back to the repo automatically.
3
Any device that loads the site will fetch the same data/store.json — fully in sync.
4
If offline, the app falls back to a local cache and will sync the next time you're online.
5
Your PAT is stored only in your browser's localStorage — it is never sent anywhere except directly to the GitHub API.
